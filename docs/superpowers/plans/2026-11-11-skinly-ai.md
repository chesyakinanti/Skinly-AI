# Skinly AI Web Application Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a modern, responsive, production-quality web application called **Skinly AI** for AI-assisted skin classification, skin region detection interface, and evidence-based skincare education using Next.js App Router, TypeScript, and Tailwind CSS.

**Architecture:** Client-side Next.js App Router application with modular service modules (`skinClassificationService`, `skinDetectionService`, `ragAssistantService`, `historyStorageService`) providing transparent model connection states, client-side TensorFlow.js support for Teachable Machine, canvas bounding box rendering for YOLO, and evidence-based skincare QA.

**Tech Stack:** Next.js (App Router), TypeScript, Tailwind CSS, Lucide React, HTML5 Canvas.

**Spec:** `docs/superpowers/specs/2026-11-11-skinly-ai-design.md`

## Global Constraints

- Primary Rose: `#A4556B`, Soft Blush: `#F3E3E7`, Warm Cream: `#FCF8F6`, Deep Mauve: `#64424D`, Sage Green: `#A9B8A2`, White: `#FFFFFF`
- Supporting colors: Normal `#A9B8A2`, Dry `#A9BDCC`, Oily `#D58B9B`, Combination `#B7A7C9`, Warning `#E8B77D`
- Headings in Plus Jakarta Sans, body text in Inter
- Preserve original assets in `assets/` without stretching, distorting, or recreating logos
- Educational non-medical disclaimer on all analysis and chat views
- Zero fabricated AI predictions or fake YOLO bounding boxes
- Minimum 4.5:1 text contrast (WCAG AA), minimum 44x44px touch targets, zero horizontal scrollbar on mobile (375px+)

## Review Focus

1. Uploading a non-image or corrupt file must display an explicit user-friendly error message, not crash.
2. Incomplete or unconfigured backend endpoints must display transparent disconnected/training banners without pretending predictions occurred.
3. Mobile viewports down to 375px must not have horizontal page overflow or overlapping controls.
4. History operations (`localStorage`) must handle storage quota errors gracefully and support deletion.
5. AI assistant queries without matching knowledge must truthfully state that the answer is not yet in the evidence base rather than hallucinating facts.
